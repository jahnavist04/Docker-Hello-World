# 🐳 Docker Hello World

My first hands-on Docker project!

A simple beginner-friendly project demonstrating how to create a Docker image and run a container using a custom Dockerfile.

## What I Learned
- Creating a Dockerfile
- Building Docker images
- Running Docker containers
- Managing containers using basic Docker commands

## Technologies
- Docker
- Alpine Linux

## Run Locally

Build the image:

```bash
docker build -t my-first-container .
```

Run the container:

```bash
docker run my-first-container
```

## Output

```text
Hello! Welcome to my first Docker container.
```

Learning Docker one container at a time! 🚀
